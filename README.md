# The Heresy Nexus

An interactive archive of every named character in the Horus Heresy and how they connect.

- `index.html` — the whole site (no build step)
- `playlist.json` — the soundtrack, played in this order. Add or reorder songs here.
- `*.mp3` — original music

If `playlist.json` is missing, the site finds every audio file in the repo by itself (sorted by name).

Character data cross-checked against [Lexicanum](https://wh40k.lexicanum.com). Unofficial fan project.
